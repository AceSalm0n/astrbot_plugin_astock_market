# 📊 AstrBot A股大盘数据插件

查询 A 股五大指数行情，查看日 K 线和交易时段复盘，支持指数异动提醒、定时群推送与 LLM 解读。

**版本 1.3.0** · [查看本次更新](CHANGELOG.md#130---2026-11-09)

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL%20v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

## ✨ 功能

- **行情查询**：上证指数、深证成指、创业板指、科创50、沪深300。
- **智能解读**：保留行情，附加指数表现、差异与数据局限说明。
- **趋势研判**：可选的 3—5 交易日分析，结合历史涨幅、均线和波动指标。
- **图片卡片**：默认优先图片，数据、图表和解读可合在同一张图。所有卡片共用上传背景和液态柔光玻璃样式。
- **定时推送**：支持多个时间点、多个群组及手动休市日期。
- **异动提醒**：盘中按涨跌幅越线或前 20 个交易日区间突破提醒。
- **交易时段报告**：午间小结、收盘复盘，支持按日存档和可选群推送。
- **历史走势图**：20／60 个交易日的收盘对比图和单指数日 K 线。

## 🚀 快速开始

1. 在 AstrBot 插件管理中安装[本仓库](https://github.com/AceSalm0n/astrbot_plugin_astock_market)。
2. 打开本插件配置，按需选择输出方式、LLM 提供商和推送群组，保存并重载插件。
3. 发送 `/大盘` 查看行情、`/收盘复盘` 查看最近一次收盘，或用 `/指数走势 上证 60` 查看日 K 线。命令前缀以你的 AstrBot 设置为准。

异动、午间／收盘报告的自动推送、旧定时推送和趋势分析默认关闭。使用 `/大盘分析` 前需配置可用的 LLM 提供商。

## 💬 命令

| 命令 | 用途 |
| --- | --- |
| `/大盘` | 五大指数行情 |
| `/大盘分析` | 行情 + LLM 解读；开启趋势后附加趋势研判 |
| `/大盘速报` | 仅行情，不调用 LLM |
| `/大盘状态` | 查看配置、提供商及最近历史检查状态 |
| `/大盘提供商` | 查看可用 LLM 提供商 |
| `/午间小结` | 查看当天上午行情；下午读取午间存档 |
| `/收盘复盘` | 查看最近已完成交易日的复盘 |
| `/大盘走势 [20或60]` | 查看指数收盘走势对比 |
| `/指数走势 <指数> [20或60]` | 单指数日 K 线及 MA5／10／20，可用简称或代码 |
| `/上证` / `/深证` / `/创业板` | 对应指数的详细行情 |
| `/科创50` / `/沪深300` | 对应指数的详细行情 |

图片模式适用于大盘、单指数行情、分析、午间小结、收盘复盘、异动和定时推送。行情、指标、数据说明和解读都放入同一张图。状态和提供商命令使用文字。

## ⚙️ 配置

推荐通过 WebUI 修改。主要配置如下：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `enable_scheduled_push` | `false` | 开启定时群推送 |
| `scheduled_push_times` | `09:30,11:30,15:00` | 24 小时制，多个时点用逗号分隔 |
| `scheduled_push_groups` | `[]` | 目标群号列表；先在目标群使用大盘命令学习映射 |
| `market_closed_dates` | `[]` | 手动维护的休市日期，格式 `YYYY-MM-DD` |
| `enable_index_alerts` | `false` | 交易时段指数异动提醒 |
| `alert_thresholds_pct` | `[1, 2, 3]` | 上下方向共用的涨跌幅阈值，单位 % |
| `enable_range_breakout_alerts` | `false` | 启用异动提醒时，可追加前 20 日区间突破规则 |
| `enable_midday_report` | `false` | 交易日 11:35 准备午间小结 |
| `enable_close_report` | `false` | 交易日 15:20 准备收盘复盘 |
| `enable_image_output` | `true` | 默认图片，也可在 WebUI 选择文字。已保存的选择继续生效 |
| `card_background` | `[]` | 通过 WebUI 上传背景，仅使用第一张 |
| `enable_llm_analysis` | `false` | 为定时行情推送及最终版午间／收盘报告附加 LLM 解读 |
| `enable_trend_analysis` | `false` | 为分析命令及启用 LLM 的推送增加趋势研判 |
| `llm_provider_id` | 空 | 选择已配置的提供商；留空按宿主默认规则解析 |

`/大盘分析` 可直接调用 LLM，不受推送开关 `enable_llm_analysis` 限制。旧字段 `llm_model` 仅保留兼容，优先通过提供商选择模型。

### 定时推送

- 统一使用北京时间，周末及 `market_closed_dates` 中的日期跳过。
- 休市日期留空时**仅过滤周末**，需按交易所公告维护；趋势日历不会自动补全推送休市配置。
- 时点自动排序去重，最多允许晚 60 秒启动；过期跳过，重启不补发。同批行情、图片和解读共用一次处理。

### 图片与背景

- 在「行情输出方式」中选择「图片」，再从「卡片背景图片」上传静态 JPG、PNG 或 WebP。升级后继续使用已保存的输出方式和背景配置。
- 所有图片输出共用第一张背景。行情、午间小结、复盘、异动和走势图都使用柔光玻璃面板，复盘内嵌的 K 线也融入背景。背景居中裁剪，处理上限为 **10 MiB、2000 万像素**。清空配置或图片异常时回退浅色样式。
- 明细里的涨跌、5／20 日收益、均线偏离和较开盘变化使用红涨、绿跌、灰平。点位、均线数值和振幅用中性色。
- 背景存放在插件数据目录；通过面板移除时会删除对应上传文件。原生上传功能需要 AstrBot **4.13.0+**。
- 缺少绘图依赖、中文字体或绘图失败时，自动回退完整文字。OneBot 明确拒绝新报告或异动图片时，同一次推送改发文字。网络超时的投递结果记为未知。

### 异动、报告与走势图

- 异动和报告推送共用目标群列表，分别开启，保存后重载。升级后在目标群使用一次大盘命令，绑定群会话和 OneBot 账号，再用 `/大盘状态` 检查。未绑定或账号有冲突的群会跳过新通知。
- 新主动通知仅在已核实的交易日运行，额外休市配置可停发。当前日历覆盖 2025、2026 年。启用报告后，可在旧定时推送中按需去掉 11:30／15:00 时点。
- 异动按分钟采样，过滤未知时间、过期与跨来源报价。每条规则每日最多触发一次，同指数同方向冷却 5 分钟，每群每日最多 6 条。启动与午休后先建立基线；采样可能错过短暂越线。
- 午间报告只使用当天 11:25 至 11:30 的有效报价，11:40 后读取存档。收盘报告只使用已完成的日线。报告会标出缺失指数，并保留近 30 天。可通过现有 LLM 开关为最终报告附加解读。
- 对比图使用共同日期起点的相对变化。单指数图使用日线开、高、低、收绘制蜡烛，红涨、绿跌、灰平，并叠加均线。图注注明实际样本数和来源。收盘复盘图片内嵌上证日 K 线，缺少上证历史时使用首个可用指数。走势命令独立尝试图片，失败回退文字。

## 🔎 3—5交易日趋势

在配置中开启“启用3—5交易日趋势分析”即可；普通行情、速报和单指数查询不会额外获取历史日线。

| 项目 | 规则 |
| --- | --- |
| 观察区间 | 以合格收盘日 T 为基准，观察 **T+3 至 T+5 交易日**，不是自然日，也不从查询时刻重新计时 |
| 基准日 | 交易日 15:15 前要求上一交易日，之后要求当日；周末和节假日使用最近合格交易日 |
| 收盘确认 | 当日日线需与独立盘后行情核对日期、时间和开高低收；无法确认时不生成趋势 |
| 历史数据 | 东方财富日线 → 腾讯未复权日线，每只指数不混拼来源；最多保留 60 日，至少需要 21 个连续有效收盘 |
| 指标 | 5/10/20 日累计涨幅、均线与偏离，20 日日收益波动及价格区间 |
| 整体判断 | 上证、深证、沪深300历史均合格才允许整体研判，否则标注“整体证据不足” |
| 数据不足 | 部分失败只分析合格指数；全部失败时提示“趋势不可用”，按原快照规则决定是否解读 |

- 日历目前覆盖 **2025、2026 年**，需逐年维护。基准年份未覆盖或与相关手动休市日期冲突时停止趋势；目标区间跨入未知年份时仅显示相对交易日。
- 模型依次解释“市场状态、3—5交易日趋势、观察条件、数据局限”，包含依据和反向证据；正文完整保留。
- 历史成交额口径尚未完全核实，**不提供成交额比较指标，不据此判断放量或缩量**。
- **预测准确率未经验证**；程序固定日期和数据状态，模型正文仍可能出现事实或逻辑错误。

## 📌 数据与使用边界

行情源自动降级：**东方财富 → 腾讯财经 → 新浪财经**。五只指数并发获取，失败指数不影响其余结果。

| 项目 | 说明 |
| --- | --- |
| 时间与状态 | 分别显示行情时间、采集时间及缓存状态，可能混合来源和时间；时间未知不能视为实时，非交易时段可能返回历史行情 |
| 统计口径 | 未知值不填零；涨跌数量仅代表监控指数，合计成交额仅统计上证与深证且要求两者有效 |
| 缓存 | 行情成功缓存 10 秒，历史成功缓存 15 分钟；并发查询复用在途请求 |
| 耗时 | 行情采集预算 18 秒、历史 12 秒；LLM 快照 30 秒、趋势 90 秒。趋势命令可能接近 120 秒，另加绘图及发送时间 |
| 分析失败 | 模型异常、空白或超时保留行情，指定提供商失效不切换其他模型；已知过期快照跳过当日解读，合格历史仍可用于周末趋势 |

本插件不含行业资金流、新闻或全市场涨跌家数数据。行情及模型结果仅供学习研究，**不构成投资建议**；第三方数据和模型输出不保证准确、完整或实时，投资风险由使用者自行承担，请合法合规使用。

## 🔧 依赖

- `aiohttp`：行情请求，AstrBot 通常已包含。
- `Pillow`：仅图片模式需要；缺失时在 **AstrBot 实际使用的 Python 环境**安装：

```shell
python -m pip install Pillow
```

图片模式还需系统中文字体，如微软雅黑、苹方、Noto Sans CJK 或文泉驿正黑。插件不会自动安装依赖或下载字体；Linux 容器请自行准备中文字体。
