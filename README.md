# AstrBot A股大盘数据插件

基于 AstrBot + NapCat 框架的 A 股大盘指数数据插件，支持实时行情查询、定时推送、LLM 智能分析。

## 功能

- **实时行情查询** — 上证指数、深证成指、创业板指、科创50、沪深300
- **LLM 智能分析** — 接入大模型解读市场情绪、板块轮动、风险提示
- **定时推送** — 支持多个时间点自动推送（默认 09:30 / 11:30 / 15:00）
- **多数据源容灾** — 东方财富 → 腾讯财经 → 新浪财经 自动切换

## 命令

| 命令 | 说明 |
|------|------|
| `/大盘` | 获取五大指数实时行情 |
| `/大盘分析` | 获取行情 + LLM 智能解读 |
| `/大盘速报` | 仅获取行情，不含 LLM |
| `/大盘状态` | 查看插件推送配置状态 |
| `/大盘提供商` | 查看可用 LLM 提供商列表 |
| `/上证` | 查询上证指数（000001） |
| `/深证` | 查询深证成指（399001） |
| `/创业板` | 查询创业板指（399006） |
| `/科创50` | 查询科创50（000688） |
| `/沪深300` | 查询沪深300（000300） |

## 配置

在 AstrBot 管理后台或 `plugins.yaml` 中添加：

```yaml
astrbot_plugin_astock_market:
  enable_scheduled_push: true            # 是否启用定时推送（默认 false）
  scheduled_push_times: "09:30,11:30,15:00"  # 推送时间点，逗号分隔
  scheduled_push_groups:                 # 目标群组号列表
    - "123456789"
  enable_llm_analysis: false             # 推送时是否使用 LLM 分析
  llm_provider_id: ""                    # 指定 LLM 提供商 ID（留空则自动检测）
  llm_model: ""                          # 指定 LLM 模型名（留空则用 provider 默认模型）
```

### 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enable_scheduled_push` | bool | `false` | 开启后插件启动时会自动开始定时推送循环 |
| `scheduled_push_times` | string | `"09:30,11:30,15:00"` | 24 小时制，逗号分隔多个时间点 |
| `scheduled_push_groups` | list | `[]` | 填写群号（纯数字），首次使用 `/大盘` 命令会自动学习群映射 |
| `enable_llm_analysis` | bool | `false` | 开启后推送内容会经过 LLM 分析再发送 |
| `llm_provider_id` | string | `""` | 指定 LLM 提供商 ID（如 `阿里云百炼_source/deepseek-v4-flash`），使用 `/大盘提供商` 查看可用列表。留空自动检测 |
| `llm_model` | string | `""` | 指定使用的模型名称（如 `deepseek-chat`、`qwen3.5-plus`），留空则使用 provider 默认模型。仅在 `llm_provider_id` 不为空时生效 |

## 数据源

主数据源为**东方财富 push2 接口**，请求失败时自动降级：

```
东方财富 push2 → 腾讯财经 qt.gtimg.cn → 新浪财经 hq.sinajs.cn
```

覆盖的五只指数：

| 指数 | 代码 | 说明 |
|------|------|------|
| 上证指数 | 000001 | 上海证券交易所综合股价指数 |
| 深证成指 | 399001 | 深圳证券交易所成份股价指数 |
| 创业板指 | 399006 | 创业板综合指数 |
| 科创50 | 000688 | 科创板50成份指数 |
| 沪深300 | 000300 | 沪深300指数 |

## 注意事项

1. **数据延迟**：东方财富 API 为实时接口，但可能存在 1-3 秒延迟，请勿用于高频交易。
2. **交易时段**：非交易时段数据为最近收盘价，定时推送在周末自动跳过。
3. **LLM 可用性**：`/大盘分析` 和 `enable_llm_analysis` 需要 AstrBot 已配置 LLM 提供商（如 OpenAI、Claude 等），否则降级为纯数据输出。
4. **群映射学习**：首次在群内使用 `/大盘` 类命令时会自动记录 `unified_msg_origin`，用于定时推送回退路径。
