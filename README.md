# AstrBot A股大盘数据插件

基于 AstrBot + NapCat 框架的 A 股大盘指数数据插件，支持实时行情查询、定时推送、LLM 智能分析。

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL%20v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

## 功能

- **实时行情查询** — 上证指数、深证成指、创业板指、科创50、沪深300
- **LLM 智能分析** — 保留原始行情，附加有数据依据的指数表现与差异解读
- **定时推送** — 支持多个时间点自动推送（默认 09:30 / 11:30 / 15:00）
- **多数据源容灾** — 东方财富 → 腾讯财经 → 新浪财经 自动切换
- **并发与缓存** — 五个指数并行获取，同指数共用在途请求，行情成功缓存 10 秒
- **数据状态说明** — 展示来源、行情时间、实际采集时间及缓存年龄，明确标注缺失数据
- **本地行情卡片** — 可选 Pillow 图片输出，红涨绿跌，保留平盘、未知和缺失；默认关闭

## 命令

| 命令 | 说明 |
|------|------|
| `/大盘` | 获取五大指数实时行情 |
| `/大盘分析` | 获取行情 + LLM 智能解读 |
| `/大盘速报` | 仅获取行情，不含 LLM |
| `/大盘状态` | 查看插件推送配置状态（含 LLM 提供商和模型） |
| `/大盘提供商` | 查看可用 LLM 提供商列表（也可在 WebUI 插件配置中直接选择） |
| `/上证` | 查询上证指数（000001） |
| `/深证` | 查询深证成指（399001） |
| `/创业板` | 查询创业板指（399006） |
| `/科创50` | 查询科创50（000688） |
| `/沪深300` | 查询沪深300（000300） |

开启 `enable_image_output` 后，`/大盘`、`/大盘速报` 和定时推送输出行情卡片；`/大盘分析` 输出卡片及后附文字解读。定时推送是否附加解读仍由 `enable_llm_analysis` 控制。单指数、状态和提供商命令保持文字；最高、最低、昨收等详细字段可通过单指数命令查看，或关闭图片配置后查看完整文字。

## 配置

在 AstrBot 管理后台或 `plugins.yaml` 中添加：

```yaml
astrbot_plugin_astock_market:
  enable_scheduled_push: true            # 是否启用定时推送（默认 false）
  scheduled_push_times: "09:30,11:30,15:00"  # 推送时间点，逗号分隔
  scheduled_push_groups:                 # 目标群组号列表
    - "123456789"
  market_closed_dates: []                # 额外休市日期，YYYY-MM-DD 列表，需按年度维护
  enable_image_output: false             # 本地行情卡片（默认 false，需要 Pillow 和中文字体）
  enable_llm_analysis: false             # 推送时是否使用 LLM 分析
  llm_provider_id: ""                    # 在 WebUI 中点击「选择提供商」直接挑选（留空则自动检测）
  llm_model: ""                          # （已废弃，通过上方提供商选择即可）
```

### 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enable_scheduled_push` | bool | `false` | 开启后插件启动时会自动开始定时推送循环 |
| `scheduled_push_times` | string | `"09:30,11:30,15:00"` | 24 小时制，逗号分隔多个时间点 |
| `scheduled_push_groups` | list | `[]` | 填写群号（纯数字），首次使用 `/大盘` 命令会自动学习群映射 |
| `market_closed_dates` | list | `[]` | 手动维护的额外休市日期，格式为 `YYYY-MM-DD`；留空仅过滤周末 |
| `enable_image_output` | bool | `false` | 大盘类命令及推送使用本地 PNG 卡片；依赖、字体或绘图失败时回退完整文字 |
| `enable_llm_analysis` | bool | `false` | 开启后推送内容会经过 LLM 分析再发送 |
| `llm_provider_id` | string | `""` | 在 AstrBot 管理后台插件配置页面点击「选择提供商」直接挑选模型列表中的某一项。留空自动检测 |
| `llm_model` | string | `""` | ⚠️ **已废弃**，通过上方「LLM 提供商」选择时已自带模型信息。此处仅保留旧配置兼容 |

## 数据源

主数据源为**东方财富 push2 接口**，请求失败时自动降级：

```
东方财富 push2 → 腾讯财经 qt.gtimg.cn → 新浪财经 hq.sinajs.cn
```

覆盖的五只指数：

| 指数 | 代码 | 说明 |
|------|------|------|
| 上证指数 | 000001 | 上海证券交易所综合股价指数 |
| 深证成指 | 399001 | 深圳证券交易所成份股价指数 |
| 创业板指 | 399006 | 创业板综合指数 |
| 科创50 | 000688 | 科创板50成份指数 |
| 沪深300 | 000300 | 沪深300指数 |

## 依赖

- `aiohttp` — HTTP 请求（AstrBot 通常已内置）
- `Pillow` — 图片模式的可选依赖，延迟导入；当前 AstrBot 宿主通常已包含

如图片模式提示缺少 Pillow，请在 **AstrBot 实际使用的 Python 环境**中安装：

```powershell
python -m pip install Pillow
```

绘图尝试系统中文字体：Windows 微软雅黑或黑体，Linux Noto Sans CJK 或文泉驿正黑，macOS 苹方。首版不打包、下载字体；Linux 容器需自行安装相应字体（例如 Noto Sans CJK）。找不到可用中文字体时回退文字，避免生成方框字符。运行时不保存临时图片，也不自动安装依赖。

### 卡片口径与回退

卡片固定保留五个指数位置；“涨跌未知”表示已获取点位但涨跌幅未知，“缺失”表示未获取到该指数行情，两者分别统计。数量仅代表监控指数，合计成交额仅包含上证与深证，并要求两者均有效。

响应时间和缓存年龄以同一份行情的 `fetch_time` 为基准，统一显示北京时间；早于响应日期的报价标为历史行情，行情时间未知或混合来源、时间时明确提示。当天报价也不自动认定为实时行情。

Pillow、字体、绘图或命令图片消息构造失败时，输出现有完整文字；LLM 失败仍可输出卡片及失败说明。命令通过宿主响应流程发送，插件不能保证图片实际发送失败后自动补发文字，可关闭图片配置重新查询。

定时推送同一批行情只绘图一次、最多分析一次，沿用 OneBot 和已学习群映射路径。图片路径均失败后仅对该群尝试完整文字，复用已有解读，不重新处理整批。映射发送返回 `false` 不计成功。发送超时可能出现送达状态不明，回退不能保证绝对无重复。

## 注意事项

1. **数据时间**：查询时间是响应生成时间，采集时间是接口实际获取时间，行情时间是数据源给出的报价时间，三者分别展示。来源无法提供可靠行情时间时显示“未知”，不能据采集时间认定行情实时；不同指数也可能来自不同来源或不同时间。
2. **缓存与超时**：成功行情缓存 10 秒，失败结果冷却 3 秒；同指数的并发查询共用请求。定时推送绕过已有缓存，但可复用正在获取的请求。每次行情源请求超时 5 秒，每个指数降级链预算 18 秒；到期停止采集并回收任务，取消清理可能带来额外耗时。失败指数不影响其他已获取指数，不使用过期缓存冒充新行情。
3. **定时推送**：统一按北京时间 UTC+8 调度，时间点排序去重；周末及已配置休市日期跳过。`market_closed_dates` 需按交易所年度公告维护，默认空列表只过滤周末，并非完整交易日历。允许目标时间后 60 秒内启动推送，消息到达时间还受采集、分析和发送耗时影响；超期跳过，重启不补发错过的时间点。同一运行周期每个槽位只尝试一次，失败不自动重发整批。更改启用状态后按 AstrBot 插件重载流程生效。
4. **LLM 可用性与边界**：`/大盘分析` 和 `enable_llm_analysis` 需要已配置的提供商。提供商解析与生成共用 30 秒预算；异常、超时或空白输出时保留文字行情或卡片并附失败说明，明确指定的提供商失效时不切换到其他模型。成功时也保留文字行情或卡片，模型解读最多 300 字；提供给模型的输入始终包含完整文字行情。已知行情日期早于北京时间当天时跳过当日分析；行情时间未知时仅允许注明局限的受限解读。指数行情不包含板块资金流、新闻和全市场股票涨跌家数，提示词限制不能保证模型永远不产生无依据结论。
5. **群映射学习**：首次在群内使用 `/大盘` 类命令时会自动记录 `unified_msg_origin`，用于定时推送回退路径。
6. **缺失与统计口径**：未知字段不等于零，未知涨跌幅不计作平盘。合计成交额仅统计上证与深证，并要求两者成交额都有效。非交易时段可能返回最近交易日数据，请勿用于高频交易。

## 开发验证

在插件目录运行离线回归测试：

```powershell
python -X utf8 -m unittest discover -s tests -v
```

测试使用固定行情响应、模拟时钟和最小 AstrBot SDK 替身，不调用真实 LLM 或发送群消息。它们验证插件逻辑，不代表实际 AstrBot 加载或 NapCat 联调通过。

渲染测试需要 Pillow 和可用的系统中文字体，会检查实际 PNG、涨跌颜色、缺失与时间说明、长文本换行边界；图片输出测试覆盖绘图失败、LLM 降级和多群回退。示例卡片使用固定数据，仅用于版面检查，不代表真实市场行情。
